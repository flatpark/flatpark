# Security policy

Report a package or app release that puts users at risk with the
[Security problem](https://github.com/flatpark/flatpark/issues/new?template=6-security.yml)
issue form, in public so other users are warned. Report a weakness in
FlatPark's own pipeline (building, signing, publishing, workflows)
[privately](https://github.com/flatpark/flatpark/security/advisories/new).
Both are handled first.

What counts, what happens to a dangerous release, and how the repository is
signed: [docs/project/security.md](docs/project/security.md).
