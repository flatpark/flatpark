| Warning: You are running an unofficial Flatpak version of Visual Studio Code !!! |
------------------------------------------------------------------------------------

This version is running inside a container and is therefore not able
to access SDKs on your host system!

To execute commands on the host system, run inside the sandbox:

  $ host-spawn <COMMAND>

To make the Integrated Terminal automatically use the host system's shell,
you can add this to your profile settings:

{
  "terminal.integrated.defaultProfile.linux": "bash",
  "terminal.integrated.profiles.linux": {
    "bash": {
      "path": "host-spawn",
      "args": ["bash"]
    }
  }
}

This is FlatPark's community package. It runs on the Freedesktop Platform
runtime, which has no compilers or language toolchains; use the ones on your
host through host-spawn.

To get languages or tools inside the sandbox instead, install SDK extensions.
They are not part of FlatPark; they come from the Flathub remote, which you can
add with:

  $ flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Then, for example:

  $ flatpak install flathub org.freedesktop.Sdk.Extension.dotnet
  $ flatpak install flathub org.freedesktop.Sdk.Extension.golang
  $ FLATPAK_ENABLE_SDK_EXT=dotnet,golang flatpak run com.visualstudio.code

Similarly for shells and other tools, also from Flathub:

  $ flatpak install flathub com.visualstudio.code.tool.fish
  $ flatpak install flathub com.visualstudio.code.tool.podman

You can use

  $ flatpak search <TEXT>

to find others.
