This version runs inside a Flatpak sandbox, with flatpark-spawn: when
VS Code, its terminal or an extension runs a command your system has
(git, node, python, go, gh, your mise/asdf toolchains, ~/.local/bin),
it runs on your system, with your PATH and configuration, as if VS Code
were installed there. Commands only the sandbox has run in the sandbox.
https://github.com/flatpark/flatpark-spawn

That means these commands run outside the sandbox, as you. To turn it
off, so that VS Code only uses what the sandbox has:

  $ flatpak override --user --no-talk-name=org.freedesktop.Flatpak com.visualstudio.code

To keep a command in the sandbox although your system has one of the
same name, list it in FLATPARK_SPAWN_LOCAL:

  $ flatpak override --user --env=FLATPARK_SPAWN_LOCAL=python3:go com.visualstudio.code

To open your system's own login shell in the Integrated Terminal, add a
profile that runs flatpark-spawn with no command (host-spawn, which this
package used to bundle, still works in existing profiles):

{
  "terminal.integrated.defaultProfile.linux": "host",
  "terminal.integrated.profiles.linux": {
    "host": {
      "path": "flatpark-spawn"
    }
  }
}

When your system lacks a command, this Flatpak's own development
environment (gcc, python, etc.) is used. To see what's available:

  $ flatpak run --command=sh com.visualstudio.code
  $ ls /usr/bin (shared runtime)
  $ ls /app/bin (bundled with this flatpak)

This is FlatPark's community package. To get support for additional languages
or tools within the Flatpak, install SDK extensions. They are not part of
FlatPark; they come from the Flathub remote, which you can add with:

  $ flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Then, for example:

  $ flatpak install flathub org.freedesktop.Sdk.Extension.dotnet
  $ flatpak install flathub org.freedesktop.Sdk.Extension.golang
  $ FLATPAK_ENABLE_SDK_EXT=dotnet,golang flatpak run com.visualstudio.code

A command from an SDK extension that your system also has runs on your
system; add it to FLATPARK_SPAWN_LOCAL (above) to use the extension's.

Similarly for shells and other tools, also from Flathub:

  $ flatpak install flathub com.visualstudio.code.tool.fish
  $ flatpak install flathub com.visualstudio.code.tool.podman

You can use

  $ flatpak search <TEXT>

to find others.
