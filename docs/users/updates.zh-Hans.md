# 更新

和其他 Flatpak 应用一样运行 `flatpak update`，或者交给软件中心：

```sh
flatpak --user update
```

## 新版本怎么来

FlatPark 盯着每个应用的官方发布。很多开发者一发版就会通知 FlatPark，其余的每天检查两次。新版本会被重新固定校验和、确认能装上，然后发布，通常在上游发版后几分钟到几小时内完成，不需要有人逐个批准。

更新时你下载的是开发者自己发布的新版本：和安装时一样，Flatpak 从开发者的服务器下载，在你的电脑上解包。

## 运行时一起升级

每个应用都用它所在运行时（Flatpak 应用共用的基础环境）的当前版本。运行时出新版本时，整个目录一起切过去、一起测试，所以你不会为了某个没跟上的应用在磁盘上多留一份旧运行时。切换之后，`flatpak update` 会下载一次新运行时，`flatpak uninstall --unused` 可以删掉旧的（见[清理](cleanup.md)）。
