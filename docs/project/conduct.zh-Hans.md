# 行为准则

FlatPark 是一个小型社区项目，规则很简单。

## 尊重他人

尊重每一个人。无论是在 issue、Pull Request、commit 消息还是任何其他项目空间中，我们都不欢迎骚扰、人身攻击、歧视和蓄意扰乱秩序的行为。

## 适用范围

本准则适用于 FlatPark repo 中的所有参与活动，包括 issue、Pull Request、review 和讨论。

## 报告问题

如果你亲历或目睹了不可接受的行为，请新建 issue（并清楚标明其性质），或通过维护者 GitHub 个人资料中的电子邮件私下联系。我们会对报告内容保密处理。

## 执行

维护者可以编辑、隐藏或移除违反本准则的贡献，也可以禁止屡次违规或行为严重者参与本项目。
